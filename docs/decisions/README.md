# docs/decisions/ — 設計判断の記録

チームで決めたことを **1判断 = 1ファイル** で残す場所。
「なぜこうしたんだっけ?」を後から誰でも辿れるようにする。

## いつ書くか

- 週次MTGやIssueで「決定」になったとき (例: アート方向性、スキーマ変更、
  機能の縮退判断)
- 迷ったら書く。3行でもよい

## ファイル名

`YYYY-MM-DD-短い内容.md` (例: `2026-07-20-art-direction.md`)

## 書式 (コピペ用テンプレート)

```markdown
# 決定: (一行で)

- 日付: YYYY-MM-DD
- 決めた人: (MTG全員 / Taka / B1+U2 など)
- 関連: (Issue #番号 / 関連文書へのリンク)

## 何を決めたか

## なぜ (比較した案があれば負けた案も)

## 影響 (誰が何を変える必要があるか)
```
