# 決定: 会議ラウンドは固定 R=2 のままにする (適応的な打ち切りは採用しない)

- 日付: 2026-09-11
- 決めた人: Taka (A)
- 関連: `DESIGN.md` §3(6) 会議調停 / §9 リスク表「会議で推論が遅い → R=2 / bid分散が大きい局面のみR増」/
  `scripts/eval_adaptive_council.py` / `checkpoints/adaptive_council_eval.json`

## 何を決めたか

DESIGN.md §9 が推論コスト対策として挙げていた **「bid分散が大きい局面のみ R を増やす」を実装しない**。
会議のラウンド数は既定の **R=2 固定**を維持する。

代わりに、この調査で見つかった **オラクル上限 +13.8pt** を今後の研究項目
(停止ヘッドの学習) として記録する。

## 測ったこと

`phase37.pt` / floodgate 検証 64 局 = **7,846 局面**。1 局面につき R=0..4 をすべて回し、
各 R での一致と、停止判断に使える統計 (方策マージン、bid の分散・首位差、
argmax が前ラウンドから変わったか) を記録して、あとから閾値を掃引した。

### 固定ラウンドの基準線

| R | 一致率 |
|---|---|
| 0 | 28.66% |
| 1 | 41.70% |
| **2** | **46.16%** |
| 3 | 43.74% |
| 4 | 40.26% |

会議の効果は +17.5pt、行きすぎの害は -5.9pt。2026-08 に phase34 で測った表
(32.0 / 34.4 / 35.5 / 35.3 / 32.7) より差がはっきり出た。

### 手作りの停止則はどれも固定 R=2 に届かなかった

| 停止則 | 最良の一致率 | 平均ラウンド |
|---|---|---|
| 収束判定 (argmax が変わらなくなったら止める) | 44.40% | 1.82 |
| 方策マージン | 43.54% | 1.99 |
| bid 首位差 | 43.35% | 2.23 |
| **bid 分散** (§9 が挙げていた案) | **41.64%** | 1.06 |

§9 の案が**最下位**だった。計算を 9% 減らして 1.76pt 失う取引にしかならない。

## なぜ効かないか

会議は収束しない。argmax が前ラウンドから変わる割合は

| 遷移 | 変化率 |
|---|---|
| R=0→1 | 54.3% |
| R=1→2 | 32.0% |
| R=2→3 | 22.1% |
| R=3→4 | **22.2%** |

3→4 でも 22% あり、**下げ止まっている**。一度収束しても次のラウンドで答えが変わるので、
「収束したら止める」は原理的に成立しない。R=3,4 で一致率が落ちるのも、この揺れが
改善ではなくノイズだから。

## それでも配分の余地は大きい (今後の研究項目)

局面ごとに最良のラウンドを選べたとしたら:

| | 一致率 |
|---|---|
| 固定 R=2 (最良の定数) | 46.16% |
| **オラクル (R=0..4 から最良を選択)** | **59.93%** |
| オラクル (R≤2 に限定) | 55.33% |

**+13.8pt の天井がある。** R を 0/1/2 の 3 択に絞っても +9.2pt。
「難所だけ長く考える」という発想自体は正しく、判断に必要な情報が今回試した
4 統計に入っていないだけ、と言える。

→ 次にやるなら **停止ヘッド**: trunk の hidden から「このラウンドで止めるべきか」を
予測する小さな head を、オラクルのラベルで教師あり学習する。既存の蒸留データで
済むので追加の対局は不要。

(注: オラクルの「平均 0.51 ラウンド」は、正解が複数ラウンドで並んだとき最小の R を
選ぶタイブレークによるもので、計算量の指標としては読めない。)

## 影響

- 推論の既定は変わらない (`council.DEFAULT_ROUNDS = 2` のまま)。Unity 側・
  `play_server.py` に変更なし。
- `scripts/eval_adaptive_council.py` を追加した。停止則を試したくなったら
  再実行できる (CPU で約 7 分)。
- 発表では「議論は 2 ラウンドで頭打ち、ただし配分には +13.8pt の余地」として
  1 枚に載せる (`docs/figures/council_rounds.png`)。
