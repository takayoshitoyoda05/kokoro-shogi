# 決定: PPO長期実行のエントロピー係数 c3 を 0.01 → 0.03 に引き上げ

- 日付: 2026-08-31
- 決めた人: Taka (A) — 事前合意の「プランA」を発動条件成立により実行
- 関連: `DESIGN.md` §4b / `configs/base.yaml` loss.c3 /
  [`2026-08-27-phase3c-to-7.md`](./2026-08-27-phase3c-to-7.md)

## 何を決めたか

phase37 からの本走PPO (ppo2、games-per-iter 64・pool 12) で、方策エントロピー H が
c3=0.01 の平衡点 (H≈1.0) まで単調低下し、iter 800 以降 **H<1.0 が持続**した
(0.92〜0.98)。事前に合意した発動条件「H<1.0 が10イテレーション持続」の成立を受け、
打ち切りではなく **c3 を 0.03 に上げて最新 ppo2.pt から再起動**する (プランA)。

## 背景の観測

- 対アンカー (phase37) 勝率は iter 300 以降 0.74〜0.91 で振動 (平均0.84、
  ばらつきは40局評価の理論ノイズと同水準) = **実勢は高原**
- H は 1.48 (iter 50) → 1.0近傍 (iter 550〜) → 1.0割れ (iter 800〜) と単調低下
- 決着率・平均手数は健全のまま (ハメ手収束の兆候なし)
- 仮説: c3=0.01 の平衡探索量では新しい勝ち筋の発見が細り、高原の一因になっている

## 追記 (同日 22:30): c3=0.03 は過剰 → 0.02 へ中間調整

c3=0.03 で再起動後、Hは20イテレーションで1.17へ回復 (量の回復は成功) したが、
対アンカー勝率が 0.79→0.60 に低下。切り分けのため **argmax診断** (τ=0.01 で
40局、尖り具合に不変な評価) を実施:

- t3 (再起動後 iter≈100) vs t2 (プランA直前 iter≈720): **勝率 0.263**
- → 手の散らばりでは説明できず、**エントロピー勾配が手の順位自体を悪化させた**
  (知識損傷) と判定

対処: c3=0.02、**損傷前の ppo2_t2.pt から再起動** (c3=0.03 下の学習約130
イテレーションは破棄)。教訓: エントロピー係数の3倍化は本モデルには強すぎる。
測定手法として「argmax診断はτサンプリング評価の交絡 (尖り効果) を除去できる」
ことを確認 — 以後の標準診断とする。

## 追記2 (同日 23:40): c3=0.02 も侵食 → **0.01 へ全面回帰で決着**

c3=0.02・t2再出発の系列でも、対アンカー勝率 0.64→0.64→0.50 と低下し、
argmax診断 (現在 vs t2) は **0.050** — 0.03のときより深い知識侵食を検出した。

結論: **エントロピー係数の引き上げは、倍率によらずこのモデルの知識
(僅差のlogit序列) を侵食する**。プランA路線を放棄し、c3=0.01・t2から再起動。
H≈1.0 の平衡は「探索枯れ」ではなくこのモデル・報酬設計での自然な成熟と
みなして受容する (c3=0.01 の第1系列は H≈1.0 帯で250イテレーション以上
無事故だった)。

高原対策としてのエントロピー介入は失敗と記録する。今後高原を破る手段は
(a) プール多様性の強化、(b) 学習率スケジュール、(c) Gumbel探索の導入 (発表後)
など方策そのものを壊さない経路で検討すること。

## 追記3 (同日 24:00): 分析の重大な訂正 — 「知識損傷」は誤診の可能性が高い

2つの測定欠陥が判明した:

1. **アンカーのすり替わり**: `selfplay_ppo.py` の評価アンカーは「そのrunで
   読み込んだチェックポイントのdeepcopy」である。再起動系列 (2〜4) の
   「対開始時勝率」は phase37 ではなく **t2 (0.82の強豪) が相手**だった。
   0.60〜0.64 は後退ではなく **t2超え〜互角**を意味する
2. **argmax診断の縮退**: τ=0.01 + 固定シードでは方策がほぼ決定論化し、
   40局が実質2〜4通りの同一棋譜に縮退する。0.263 / 0.050 は統計的に
   ほぼ無意味 (実質n≈2〜4)。t3 が phase37 に τ=0.1 で 0.800 と、無傷の
   t2 と同水準で勝った事実は「損傷なし」側を支持する

よって追記1・2の「知識損傷」判定は誤診の可能性が高く、c3=0.03/0.02 系列の
破棄 (計約4時間) は過剰対応だった。c3の適正値は本記録からは**未確定**に戻る。
現行は c3=0.01 (第1系列と同一の実績構成) で続行し、これ以上の再起動・係数変更は
行わない。

教訓: (a) 評価系の対戦相手が何かをコードで確認してから数字を読む。
(b) 決定論的方策同士の対局評価はシード・温度の設計次第で標本が縮退する。
τ=0.1・シード可変・十分な局数で測ること。

## 期待と検証

- H が 1.3〜1.5 帯へ回復し、探索の回復が高原突破につながるかを
  ライブはしご評価 (8時間スパンの退避スナップ同士の40局対戦) で監視する
- 副作用リスク: 短期的に対アンカー勝率が下がる可能性 (探索ノイズ増)。
  はしごで2計測連続の後退が出た場合は c3=0.02 へ中間調整を検討
