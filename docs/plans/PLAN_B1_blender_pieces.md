## 3. 駒モデリング手順 (案①/③想定の完全手順)

### 3.1 駒本体 (五角柱)
1. Add → Mesh → Circle、Vertices = **5**、Fill Type = Ngon
2. Edit Mode → 頂点を移動して将棋駒の五角形に (上が尖り、下が広い。
   実物の比率: 幅:高さ ≈ 1:1.1、上角約145°)
3. 全選択 → E (押し出し) で厚み **0.008m** → 側面に少しテーパー
   (上面をS (スケール) 0.9倍) で台形断面に
4. Ctrl+B (ベベル) でエッジに丸み (幅0.0005、セグメント2) — 光の当たりが
   良くなる。tris数を見ながら
5. Object Mode → Apply → All Transforms (スケール適用忘れはFBX事故の元)

### 3.2 UV展開と文字テクスチャ
1. Edit Mode → 表面/裏面/側面をシーム (Ctrl+E → Mark Seam) → U → Unwrap
2. テクスチャ: 2048×2048 png 1枚に14駒分の文字をアトラス化すると
   マテリアル1個で全駒いける (推奨)。文字は:
   - 楷書フォントで「歩」「王」等を画像編集ソフトで描く、または
   - Blender内 Text オブジェクト → メッシュ化 → ベイク
   - フォントのライセンス確認 (商用可のフリー毛筆フォント多数あり。出典をメモ)
3. Material: Principled BSDF、Base Color に文字テクスチャ、
   Roughness 0.4 (木のツヤ)。**Blender側の見た目は仮でよい** —
   本番の見た目はU2のURPシェーダが決める

### 3.3 シェイプキー (感情の仕込み・最重要)
1. Object Data Properties (緑の三角タブ) → Shape Keys → 「+」で **Basis** 作成
2. もう一度「+」→ 名前を **`mood_fear`** に変更 (naming.md からコピペ)
3. `mood_fear` を選択、Value=1 の状態で Edit Mode →
   駒全体をわずかに縮こませる: 全選択 → S → 0.93、Z方向にさらに S → Z → 0.95
   (すくんで小さくなる)、少し後傾 (R → X → -8°)
4. Object Mode に戻り Value を0⇄1で動かして変化を確認
5. 同様に **`mood_aggr`**: 前傾 (R → X → +10°) + わずかに拡大 (S → 1.03)
6. **注意**: シェイプキーは頂点数を変えられない。モデルの形を後から変えたら
   シェイプキーは作り直しになるので、**形を確定してからキーを作る**

### 3.4 FBXエクスポート (設定を固定して全駒同じに)
File → Export → FBX:
- Limit to: Selected Objects ✓
- Scale: 1.00 / Apply Scalings: **FBX All**
- Forward: **-Z Forward** / Up: **Y Up**
- Geometry: Apply Modifiers ✓ / **Shape Keys (Morph Targets) を含める**
  (Bake Animation は不要ならオフ)
- 出力先: `Assets/_Project/Models/Pieces/Koma_FU.fbx`

**週2の最初の1個はU1/U2と3人でUnity取り込みテスト**をして、この設定で
「大きさが合う・向きが合う・BlendShapeが見える」を確認してから量産に入る。
Unityのインポート側では Model → Blend Shapes ✓ を確認 (U2と共有)。

- 複製 → Decimate モディファイア (Ratio 0.3) → 名前 `Koma_FU_LOD1` として
  同FBXに含める。シェイプキーはLOD1では捨ててよい (遠距離では見えない)

## 5.5 キャリアUI用アイコン (週8、U2への納品物)

U2の戦績一覧画面で使う駒種アイコン14種。Blenderのレンダリングで作る:
1. 駒を正面やや上から映すカメラを1つ作り、全駒で使い回す
2. World の背景を透過に: Render Properties → Film → **Transparent ✓**
3. Output: PNG / RGBA / **256×256**
4. 14駒を順に配置してレンダ (F12) → `unity/.../UI/Icons/icon_FU.png` 〜
   の命名で納品 (SFEN駒種名と一致させる)
5. ライトはSun 1灯 + 弱いFillで十分。凝らない (アイコンは小さく表示される)
