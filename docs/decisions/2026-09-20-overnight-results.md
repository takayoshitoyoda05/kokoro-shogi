# 2026-09-20 夜間実験の結果と、強化方針の絞り込み

9/19 夜に 4 本のチェーンを走らせ、9/20 朝に結果が出そろった。
外部基準はすべて **対 Háo (YaneuraOu 9.80git + halfkp_256x2-32-32) depth 1、floodgate 序盤 500 種から
100 局、先後各 50**。序盤と手番が揃っているので、モデル間の比較は**対応あり符号検定**で行う。

## 1. 感情 GRU の解凍 — 路線を閉じる

E4c (gru-lr 1e-4 / anchor 1.0) を追加し、2 因子を分離した。

| 条件 | gru-lr | anchor | Δgru = c·√t の c | Δgru @iter100 | 外部基準 |
|---|---|---|---|---|---|
| ppo2 (解凍なし) | — | — | — | — | **0.230** |
| E4 | 1e-5 | 1.0 | 0.0056 | 0.091 | 0.175 |
| E4c | 1e-4 | 1.0 | 0.0457 | 0.455 | **0.050** |
| E4b | 1e-4 | 0.1 | 0.0490 | 0.500 | 0.110 |

**学習率だけで拡散量の 92% が説明できる。** anchor を 1.0 に戻しても GRU はほぼ同じだけ動いた
(0.0457 vs 0.0490) ので、E4 で GRU が動かなかった原因は anchor ではなく `gru-lr 1e-5` が
小さすぎたことで確定。

そして **GRU を動かすほど外部強さが下がる**関係が 4 点で一貫している (0.230 → 0.175 → 0.110 → 0.050)。
設定の問題ではなく路線そのものが有害。**「感情 GRU を PPO で育てる」は終了**。
Phase E は密な補助損失つき蒸留に切り替える (強さとは別目的として)。

## 2. 会議ループの random loop sampling — 唯一の有意な成果

学習時に会議ラウンド R をランダムに選ぶ (`--council-round-choices`, STARS 由来) 効果を、
R=2 固定の対照 `b_fix` と比較した。両者とも ppo2 から warm start、20,000 局、他は同条件。

| R | b_rls | b_fix | 対応あり | p |
|---|---|---|---|---|
| 1 | 0.175 | 0.080 | 18 勝 8 敗 | 0.076 |
| 2 | 0.190 | 0.185 | 18 勝 18 敗 | 1.000 |
| 3 | 0.165 | 0.150 | — | — |
| 4 | **0.200** | 0.040 | 18 勝 2 敗 | **0.000** |
| 6 | **0.165** | 0.000 | 18 勝 0 敗 | **0.000** |

**9/19〜20 に試した全施策の中で、対照に対し有意差が出た唯一のもの。**
ただし正確な結論は「**深くしても壊れなくなった**」であって「深さが強さを買う」ではない。
b_rls は R によらず 0.165〜0.200 で横ばいで、出発点の ppo2 (0.230) を超えていない。

→ **採用する** (既定の学習設定に入れる)。ただし強化策としてではなく頑健性の確保として。
PonderNet 停止ヘッドへの投資は、R が強さを買わない以上いったん保留。

## 3. エンジン教師蒸留 — この規模では効果なし (確定)

本走 20,000 局・全 226 シャード (2023/24/25)、教師あり `main_teacher` と
`--no-teacher` 対照 `main_control` を同条件で比較。

| | 外部基準 |
|---|---|
| ppo2 (出発点) | 0.230 |
| main_teacher | 0.180 |
| main_control | 0.160 |

差 **+0.020、13 勝 11 敗 76 分、p = 0.84**。パイロット (4k 局) でも 0.205 vs 0.205 で完全同値。
**規模を 5 倍にしても効果が出ない。** 教師データ 180 万局面は Ruoss et al. の 150 億の 1/8,000。
桁を上げるには CPU 数週間とモデル拡大が要るため、いったん棚上げ。

## 4. 深さ掃引 — depth 1 の結論は有効、ただし感度不足

| モデル | d1 | d2 | d4 |
|---|---|---|---|
| ppo2 | 0.230 | 0.130 | 0.030 |
| phase37_e3 | 0.220 | 0.130 | 0.020 |
| main_teacher | 0.180 | 0.170 | 0.070 |
| E2b culture1 | 0.100 | 0.100 | 0.030 |

順位はおおむね保たれた (E2b が最下位、ppo2/phase37 が上位) ので、**depth 1 の結論はそのまま使える**。

d4 で main_teacher が首位に見えたが、検定すると **p = 0.34** (7 勝 3 敗) で有意でない。
d1/d2 も p = 0.47 / 0.54。「教師蒸留は強い相手に効く」は**成立しない**。

**より重要な問題**: 全モデルが 0.02〜0.23 に潰れている。この帯では 100 局でも勝敗が動く局が
10〜30 しかなく、差を検出できない。統計的感度は勝率 0.5 付近で最大なので、物差しを較正する必要がある。

## 5. trunk の epoch 追加 — 唯一の正の効果 (検証中)

上の 4 つはすべて「固定された trunk の上の小細工」だった。trunk 自体の学習量を測り直したところ:

| | val 一致率 | 外部基準 |
|---|---|---|
| phase37_e2 | 40.91% | **0.110** |
| phase37_e3 (全系列の出発点) | 41.28% | **0.220** |

**1 epoch 追加しただけで +0.11** (対応あり 19 勝 8 敗、p = 0.052)。
ppo2 も E2b も教師蒸留も、この「まだ伸びている途中かもしれない trunk」の上に積んでいた。
**4 epoch 目は誰も回していない。**

注意点:
- `checkpoints/phase37.pt` は 8/31 15:14 に e3 で上書きされており (‖Δ‖=0)、e1 の重みは失われた。
  データ点は e2/e3 の 2 つのみ。
- val 一致率の伸びは +0.37pt (32 局) と小さく、頭打ちの可能性も残る。p=0.052 もぎりぎり。
- e3 の起動コマンドが未記録で lr 不明 (既定 2e-4 と仮定)。
- 1 epoch = 12.3 時間 (156k 局)。

→ **e4 を実行中** (`checkpoints/ops/trunk_e4.sh`, 9/20 12:38 開始, `--no-teacher`,
random loop sampling なし)。完了時に外部基準と e3 との対応あり検定を自動出力。

判定: **≥ 0.25 なら続行** (trunk 学習量が本命の強化策)。≈0.22 なら打ち止めで F' (構造) か拡大へ。
< 0.19 なら lr が高すぎたと見て 5e-5 で再試行。

## 決定

| 施策 | 判断 |
|---|---|
| 感情 GRU の PPO 解凍 | **閉じる** (用量反応 4 点で有害) |
| 自己対戦 PPO の追加投資 | **閉じる** (9,200 iter で +0.01) |
| 文化リーグ (強さ目的) | **閉じる** (分化の研究としては維持) |
| エンジン教師蒸留 | **棚上げ** (p=0.84、桁違いのデータが要る) |
| random loop sampling | **採用** (頑健性。強さは上げない) |
| trunk の epoch 追加 | **検証中** (e4 の結果待ち) |
| 物差しの較正 | **実施中** (`--engine-nodes` で 0.5 付近を探す) |

## 運用上の教訓

- **実行中ジョブが依存するファイルを git stash しない。** PR 用に stash した `play_server.py` を
  `eval_vs_engine.py` が import しており、c_chain の control 評価が無言で失敗した
  (エラーが `| grep "^=="` に飲まれた)。ジョブの eval 行は `grep -E "^==|Error|Traceback"` にする。
- **`mood_distill` は `.teacher.npz` があると教師損失が既定で ON** (c_soft 1.0)。
  純粋な継続学習・対照には必ず `--no-teacher`。起動ログの c_soft を確認する。
- 学習の起動コマンドはログ冒頭に残らない。ops スクリプト経由で起動し、スクリプトを残す。
- 小さい勝率差を読み過ぎない。9/19〜20 で 4 回やった (ppo2 0.48 の決定論崩壊、E4 ゲート通過、
  teach50k 0.245、main_teacher の d4 首位)。**必ず対応あり検定を通してから言う。**
