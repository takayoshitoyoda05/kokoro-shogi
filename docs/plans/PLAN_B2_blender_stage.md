B1のアート方向 (リアル/折衷) が決まったら、それに合わせて環境案を1枚:

- 10週なので背景は「カメラに映る90°分だけ作る」割り切りも有効
  (デモのカメラアングルを先に決めてしまう)

## 3. 制作手順 (完全手順)

### 3.1 盤 (週2・最優先)
1. Cube → S でサイズ 0.36 × 0.33 × 0.02m (卓上板型。脚付きは週5に判断)
2. Ctrl+B で天面エッジにベベル (幅0.002、セグメント2)
3. **マス目はモデルで彫らずテクスチャで描く** (軽い・修正が楽):
   - 2048×2048で木目 (ambientCGの Wood 系をDL: Color/Roughness/Normalの3枚)
   - その上にマス目の線 (9×9、線幅2px相当、焦げ茶) を画像編集で重ねるか、
     Blenderのテクスチャペイントで直接描く
4. UV: 天面をProject from View で真上から展開 → マス目がゆがまないよう確認
5. Material `M_Ban`: Base Color=木目+線、Roughness map接続、Normal map接続
   (Normal は Image Texture → Color Space: **Non-Color** → Normal Mapノード経由。
   ここを間違えると凸凹が出ない、定番のつまずき)
6. 原点: 天面中央 (3Dカーソルを天面中央へ → Set Origin → Origin to 3D Cursor)
7. FBX書き出し → U1に渡し、駒の配置座標 (マス幅0.036/0.033) を確定してもらう

### 3.2 駒台 (週2)
- Cube 2個: 0.12 × 0.12 × 0.10m、天面にベベル。`KomaDai_L` / `KomaDai_R`
- 盤の左右斜め前に置く前提の位置決め用Empty (目印) をシーンに入れておくと
  U1が配置しやすい

### 3.3 環境ブロックアウト (週3)
- 「大きい形から」の原則: 床 (Plane) → 壁2面 → 机/畳の面 → 光源の位置決め
- 畳: Plane 1枚 + ambientCG の Tatami/Fabric 系テクスチャでまず済ませる。
  縁 (へり) を入れるなら Array モディファイアで並べ、**適用後のtrisを確認**
- この段階のものを一度FBXでU2に渡し、Unityでの照明テストをしてもらう
  (Blender内の見た目とURPの見た目は結構違う。早めに答え合わせ)

### 3.4 本制作 (週5-6)
- テクスチャ: PBR3点セット (Color/Roughness/Normal) を素材サイトから。
  解像度は 2K で十分 (4Kは容量とロードの無駄)
- **マテリアル共有戦略**: 「木 (盤・柱・机)」「畳/布」「紙 (障子・掛け軸)」
  「金属 (小物)」の4-5個に寄せる。小物ごとに新マテリアルを作らない
  (ドローコール削減 = U2の60fps達成に直結)
- 小物 (雰囲気もの): 湯呑み・座布団・行灯・掛け軸など3-5個まで。
  各 ≤ 2k tris
- ライトはBlenderでは仮。**本番の光はUnity側 (U2) が組む**ので、あなたは
  「行灯のメッシュ」「窓の形」など光源の器を作る係

### 3.5 ライティング調整 (週6、U2とペア作業)
- U2のシーンで一緒に確認: 駒の発光が背景に埋もれないか / 盤面が暗すぎて
  マス目が見えなくならないか
- 必要なら: 壁・床の Base Color を一段暗く焼き直す、行灯まわりだけ
  明るいテクスチャに

### 3.6 スカイボックス・背景 (週8)
- Poly Haven の HDRI (夜・室内系) をDL → U2に渡してUnityのSkyboxに
- カメラに映らない面は作らない/消す (予算節約)

## 5. つまずき対策 (先回り)
- **Normal mapが効かない** → Color Space: Non-Color を確認 (§3.1の5)
- **Unityで真っ白/真っ黒** → テクスチャのpngを一緒にコミットしたか、
  マテリアルの再割り当て (URPマテリアルはU2が作るので、メッシュと
  テクスチャだけ正しく渡っていればOK)
- **スケール事故** → Export前に Ctrl+A → All Transforms (B1と同じ)
- **マテリアル増殖** → 週5のマテリアル棚卸しで5個に統合
- **素材ライセンス** → CC0でも記録する (LICENSES_textures.md)。
  CC0以外 (要クレジット素材) を使ったら発表資料に記載が必要
- 2日詰まったらB1かMTGへ (48時間ルール)。Blender操作はB1と助け合うのが最速
