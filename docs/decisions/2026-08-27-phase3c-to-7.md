## 何を決めたか

### 1. 関係性 [C] は「絆 = 味方の紐のEMA」を状態に持つ

$R^{(t+1)}_{ij} = 0.9 R^{(t)}_{ij} + 0.1\,\mathrm{bond}_{ij}$ (片紐0.5/相互1.0)。
瞬間の紐は $B_{利き}$ が既に見ているので、r_ij の存在意義は**時間積分**に置いた。
attentionへはヘッド毎スカラーの零初期化バイアス (Lc0流、B_利きと同位置)。
JSONLの `relations[].r` はこの状態の実値 (r≥0.3・5件/駒のフィルタは契約どおり)。

### 2. 会議 [D] は重み共有再適用、学習R=2・推論R可変

trunk最終2層を $[h; P^{(r)}]$ に再適用 (Universal Transformer流)。新パラメータは
提案埋め込みのみで、**Rは学習時と推論時で変えられる**。narration はLLMを使わず
テンプレート3パターン (逆転/接戦/初志貫徹) で生成 (`viz/narrator.py`)。

### 3. Phase 5 は本将棋のまま (ユーザー決定、DESIGN.mdの5五将棋想定を変更)

対局後ループの功績 $\hat A_t$ は MC advantage ($z_{手番} - V$) の mover-credit 近似
(§9の方針どおり相対比較にのみ使用。COMAの反実仮想Qは保留)。
θ_ind更新は2パス方式 (パス1: no_gradで軌跡収集 / パス2: 全手を1バッチにまとめ
て $\log\pi$ へ勾配) でVRAMを節約。E忠誠は3案のうち**ハンデ案**を実装
(κ_E=0.5、転生/リセット案は未実装)。

### 4. PPO [7] は negamax流GAE、感情GRUは凍結

価値・報酬・advantageを常に手番側視点に統一し、後続を符号反転して伝播:
$\hat A_t = \delta_t + \gamma\lambda(-\hat A_{t+1})$。desire補助損失は自己対戦
棋譜から `compute_desire_labels` でその場生成 (統一損失の「全フェーズ並走」)。
GRUのBPTTは系列蒸留の担当とし、PPO中は観測扱いで凍結。

### 5. リーグ [6] は共有trunk + Φ差し替え

文化 = θ_sp + (τ, λ_g)。optimizerも共有 (モーメントが文化間で混ざる縮退。
節あたり更新が少ないため許容)。順序は 3-C→4→5→**7→6** (リーグはPPO基盤を
再利用。DESIGN.md週次計画の週8=7, 週9=6 と同じ逆転)。

### 6. 実データの罠: game_index は棋譜ファイル内連番

隣接する別局が同じ番号になり境界検出が融合 → 学習クラッシュ。境界は
「変化点 ∪ 初期局面の行」とし、初期局面から始まらない断片は捨てる (0件を確認)。

## 夜間実行の結果 (2026-08-27 追記)

### PPO長期 600イテレーション (過去スナップショット対戦プール付き)

- 対開始時スナップショット勝率: 0.48 (iter 25) → **ピーク0.83 (iter 225)** →
  0.65〜0.77で推移、最終0.71。**蒸留モデルに対して約7割勝つ方策**になった
- value loss 0.11 → 0.019、エントロピー 2.0〜2.3 で崩壊なし
- プール: 50イテレーションごとに凍結スナップショットを追加 (最大5)、確率0.5で
  片側を過去の自分が担当。相手側の手は off-policy として学習から除外

### valence の結論: 形勢は m_i の読み出しでは取れない

駒得スイングをイベント特徴に足しても (phase35)、形勢教師への valence R² は
0.21 で変わらず。**形勢情報は trunk が持ち、駒ごとのGRUに積む勾配圧が無い**
というのが解釈。よって納品する valence は
$\mathrm{clamp}(\pm V - 0.4\,\mathrm{fear} + 0.2\,\mathrm{aggr})$ と
**モデルの value ヘッドから直接合成**する方式に決定 (ヒューリスティックと同型、
形勢成分だけ本物のVに置換)。実測 sd 0.045 → **0.882**、値域 ±1.00。
fear/aggression は引き続きGRU射影 (R² 0.40 / 0.28)。
fit_mood_projection の教師に evaluation=0 を渡していたバグも修正済み
(material_eval を渡す)。

### 文化リーグ 30世代

‖Φ−Φ′‖ は 1.1〜1.38 を振動し、**発散せず平衡** (変異と淘汰の釣り合い)。
勝率差は games_per_pair=2 では解像度不足 (多くの節で0.417〜0.583)。
フル版では節あたり対局数を増やして淘汰圧を上げる必要がある。
