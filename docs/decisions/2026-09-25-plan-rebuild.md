# 2026-09-25 計画の立て直し — 測定を厚くしてから本線を決める

`2026-09-25-stage1-gate-and-measurement.md` で前提が 2 つ崩れた (「追加学習で弱くなる」と「過学習」は
どちらも誤り)。何が確かで何が怪しいかから組み直す。

## 確かなこと / 怪しくなったこと

| 主張 | 状態 |
|---|---|
| 蒸留系モデルの強さはどれも 0.14〜0.16 (対 Háo depth1、400 局) | 確か |
| 追加学習で held-out の真似は毎 epoch 改善 | 確か (2026 年 1,000 局) |
| 転生保存則は真似の精度を上げる (policy 損失 −0.0064、6.4σ) | 確か |
| モデル同士の勝率とエンジンに対する勝率は別軸 | 確か (r = −0.14) |
| e2→e3 の +0.11 / 追加学習で劣化 / 過学習 | 撤回 |
| GRU 解凍は有害 / 文化リーグは弱くする / PPO は +0.01 | 要再測定 (すべて旧来の先頭 50 序盤で測った) |
| random loop sampling (R=6 で 0.000 vs 0.165) | 差が大きく残る見込み、要確認 |

## 最大の気づき: 測定は学習の 300 分の 1 のコスト

400 局の対エンジン評価は 3 分、1 epoch の学習は約 16 時間。安い測定をケチって高い学習の結果を読み違えていた。
今後の標準は **1,000 局 (8 分、検出下限 ≈ 0.035)**、重要な判定は 2,000 局 (序盤を増やす)。

## 計画

**フェーズ 0 (9/25)**: 9/19〜25 の作業を `feature/strength-yardstick` にまとめて push (PR は出さない)。

**フェーズ 1: 測定を固める (1〜2 日、GPU は短いジョブのみ)**
- 1a. 過去の結論を 1,000 局で総点検 — ppo2 / e2 / e3 / e4 / 文化リーグ / GRU 解凍 / random loop / 教師蒸留
- 1b. 同じモデルを held-out 1,000 局の val でも測り、「真似の精度」と「強さ」の散布図を作る
  - 相関あり → 真似の精度を速い選別の指標にできる (誤差 0.001)
  - 相関なし → floodgate の真似では強くならない。目的を変える
- 1c. 学習が WSL の 24GB 中 22GB を使い評価を並走できない。全シャードを RAM に載せる読み込みを
  メモリマップ化する

**フェーズ 2: 本線 (1b で分岐)**
- 相関あり: 2 万局の部分学習 (約 2 時間) で選別 → 勝者だけ本学習 (16 時間)。候補は EMA + 学習率
  スケジュール / 180° 回転増強 / WDL + 残り手数 / 年拡大データ / 転生保存則
- 相関なし: 強さに直結する教師 (規模を上げたエンジン教師蒸留、外部エンジン相手の学習) を検討

**フェーズ 3: 新規性の線 (並行、強さとは別)**
転生保存則の陽性結果を解釈可能性の研究として扱う。段 2〜4 (幾何・マストークン・入札均衡) は
フェーズ 1 で測定が固まるまで保留。
